# 자동 검사기

눈으로 훑어서 버그를 찾는 건 끝이 없어서, **앱을 무작위로 마구 조작하면서
"어떤 순서로 조작하든 반드시 참이어야 하는 것들"이 깨지는지** 자동으로 보는
도구예요. 깨지면 그때까지의 조작 기록이 그대로 남아서 재현할 수 있어요.

이 폴더는 배포되는 앱과 상관없어요. GitHub Pages 는 `index.html` 만 쓰고,
여기 파일들은 켜지 않으면 아무 일도 하지 않아요.

## 돌리는 법

1. 터미널에서 이 저장소 폴더로 가서 로컬 서버를 켭니다.

```bash
python3 -m http.server 8731
```

2. 브라우저에서 `http://127.0.0.1:8731/test/run.html` 을 엽니다.
   (로그인 없이 바로 앱이 뜨고, 시세·환율은 가짜 값이 나와요.)

3. 개발자 도구 콘솔에서:

```js
var s=document.createElement('script'); s.src='fuzz.js'; document.body.appendChild(s);
```

4. 잠시 뒤, 같은 콘솔에서:

```js
JSON.stringify(__fuzz(80, 1))
```

`80` 은 조작 횟수, `1` 은 씨앗(같은 숫자면 같은 조작이 반복돼요).
`실패: []` 면 통과입니다. 여러 씨앗을 돌리려면 숫자를 바꿔가며 반복하세요.

기록이 쌓이면 화면이 커져서 느려지니, 몇 번 돌린 뒤에는
`localStorage.clear()` 후 새로고침하고 다시 시작하세요.

## 무엇을 검사하나

조작 한 번마다 아래가 전부 참인지 봅니다. 하나라도 어긋나면 멈추고 알려줘요.

- **VR** — 사이클이 날짜순인지 / 앞 사이클의 V·Pool 이 다음 사이클의 출발값과
  같은지 / 보유수량이 체결 누적과 같고 음수가 아닌지 / Pool 이 입출금·체결
  누적과 같은지 / 평가금 E 가 수량×종가인지
- **무매** — 기록이 날짜순인지 / 수량·잔금이 체결 누적과 같은지 /
  **잔금 + 투입금액 = 원금 + 실현손익** 인지 / T 가 0~분할수 안에 있는지
- **직접입력 종목** — 수량·실현손익이 거래 누적과 같은지 / 수량이 음수가
  아닌지 / 거래가 날짜순인지
- **예수금** — 그외 예수금이 입출금 + 직접입력 매매 + 무매 매매의 합과 같은지

## 파일

- `run.html` — 앱을 가짜 서버로 띄우는 껍데기 (앱 코드는 복사하지 않아요)
- `stub.js` — 가짜 로그인·시세·환율 서버
- `fuzz.js` — 무작위 조작 + 위 불변식 검사
